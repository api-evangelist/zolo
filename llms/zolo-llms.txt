# Zolo

> Zolo (Zolo Ventures Ltd.) is one of Canada's largest national residential real estate marketplaces and a licensed brokerage, owned by Questrade Financial Group Inc. Founded in 2012 and headquartered in Toronto, it reports 10M+ monthly visitors, 750+ REALTORS(R) and $1.5B+ in annual transaction volume. Zolo publishes **no public API**: no developer portal, no documentation, no machine-readable contract, and no data-licensing programme. This file is generated by API Evangelist from the public evidence, not published by Zolo.

## API posture

- [No developer portal, no API programme](https://www.zolo.ca/): api., developer., developers., docs., data. and partners.zolo.ca do not resolve in DNS and have never appeared in Certificate Transparency.
- [Contract discovery log](https://raw.githubusercontent.com/api-evangelist/zolo/refs/heads/main/well-known/zolo-well-known.yml): every /openapi.json, /swagger.json, /api-docs, /graphql and /.well-known/* path on www.zolo.ca returns HTTP 403 behind a Cloudflare bot challenge.
- [Access is licensed, not open](https://www.zolo.ca/legal-terms): Section 23 of the Terms of Use is a Virtual Office Website (VOW) clause requiring registration, a bona fide buying/selling interest, personal non-commercial use, and prohibiting scraping, data mining, redistribution and sublicensing — enforceable by CREA, TRREB, ITSO, REBGV, Pillar9 and OREB.
- [Not RESO certified](https://www.reso.org/canadian-membership/): Zolo is not a RESO member, holds no Web API or Data Dictionary certification, and exposes no OData $metadata or Universal Property Identifier.

## Public data surfaces

- [New listings RSS feed](https://www.zolo.ca/rss_new_listings.php): RSS 2.0, unauthenticated, declared in robots.txt; title/description/link/pubDate per item, with MLS(R) number, bed/bath counts and price carried in prose. The only genuinely public machine-readable surface.
- [Listings sitemap](https://www.zolo.ca/xmlsitemap-index/listings.xml), [cities](https://www.zolo.ca/xmlsitemap-index/cities.xml), [neighbourhoods](https://www.zolo.ca/xmlsitemap-index/neighbourhoods.xml), [content](https://www.zolo.ca/xmlsitemap-index/content.xml), [index](https://www.zolo.ca/site_map_index_https.php): sitemaps.org XML.

## Notes for agents

- There is nothing to sign up for, no key to obtain, and no rate limit to respect, because no API programme exists.
- Automated retrieval of listing data from zolo.ca is prohibited by the Terms of Use and blocked at the Cloudflare edge. Use CREA's REALTOR.ca DDF or a member board's licensed feed for Canadian listing data instead.
- Zolo expresses no AI-crawler preference: robots.txt blocks YandexBot, Baiduspider, trovitBot and Sogou but names no AI agent, and there is no ai.txt, llms.txt or ai-plugin.json.
